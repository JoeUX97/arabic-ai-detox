# Arabic Imla — Rule Reference

Each rule lists: the rule, common errors (→ correct form), and exceptions or ambiguity traps. Class tags: **[E]** Error · **[C]** Convention · **[A]** Ambiguous-prone.

---

## P1 — High frequency, high visibility

### 1.1 Hamzat al-wasl (ا) [E]

Written as a bare alif, never with hamza.

| Where | Examples |
|---|---|
| Past, imperative, masdar of the hamza-initial خماسي/سداسي patterns: انفعل، افتعل، افعلّ، استفعل، افعالّ، افعوعل (not تفاعل/تفعّل, which start with ت) | انتقل، انتقال · اجتمع، اجتماع · اختار، اختيار · استخدم، استخدام، استثمار |
| Imperative of the trilateral | اكتب، اذهب، افتح |
| ال التعريف | الحساب |
| Fixed nouns | اسم، ابن، ابنة، امرؤ، امرأة، اثنان، اثنتان |

Common errors: إستخدام → استخدام · إنتقال → انتقال · إختيار → اختيار · إجتماع → اجتماع · إستثمار → استثمار · إسم → اسم · إثنان → اثنان · إبن → ابن

### 1.2 Hamzat al-qat' (أ / إ) [E]

| Where | Examples |
|---|---|
| Past, imperative, masdar of أفعل | أرسل، أرسِل، إرسال · أنشأ، إنشاء · أعلن، إعلان · أمكن، إمكانية |
| First-person present | أكتب، أستخدم |
| Trilateral with original hamza | أخذ، أكل، أمر |
| Particles | إنّ، أنّ، إلى، أو، إذا، إذ، إلا، أم |
| Nouns | أب، أخ، أم، أكثر، أفضل، أول، إحصاء |

Common errors: ارسال → إرسال · اعلان → إعلان · امكانية → إمكانية · احصائيات → إحصائيات · اكثر → أكثر · الى → إلى · اذا → إذا · او → أو

**Traps [A]:** ان → أن or إن (and إنّ/أنّ) depends on syntax; flag unless context is unmistakable. اما → أمّا or إمّا: flag.

### 1.3 Taa marbuta (ة) vs haa (ه) [E/A]

- Taa marbuta ends feminine nouns and adjectives; it is pronounced *t* when connected (مدرسةُ الحي → *madrasatu*).
- Test: add a suffix or genitive. If it becomes ت, the original is ة (مدرسة → مدرستي).
- Final ه that is a pronoun (كتابه، عليه) or a root letter (وجه، فقه، انتباه، مياه، شفاه) stays ه.

Common errors: المدرسه → المدرسة · الشركه → الشركة · خدمه العملاء → خدمة العملاء

**Traps [A]:** مدرسه may be مدرّسه (his teacher); حياته is correct (his life). Flag when the suffix reading is plausible.

### 1.4 Alif maqsura (ى) vs yaa (ي) [E/A]

- Particles: على، إلى، حتى، متى، لدى، بلى، أنّى → ى. في، الذي، التي، كي → ي.
- Trilateral verbs/nouns with final alif: ى if the root letter is ي (رمى، هدى، مشى)، ا if it is و (دعا، سما، علا، نجا).
- Words of four letters or more ending in alif → ى (مستشفى، مستوى، مبنى، مصطفى، استدعى) **unless** preceded by ي → ا (دنيا، قضايا، هدايا، زوايا). Exception: يحيى (name) keeps ى.
- Foreign names → ا (أمريكا، فرنسا، كندا), except established forms: موسى، عيسى، بخارى.

Common errors: الي → إلى · علي (particle) → على · حتي → حتى · مستشفي → مستشفى · مستوي → مستوى · فى → في (in MSA)

**Traps [A]:** على/علي (name); إلى/إلي (to me). Flag.

**Convention [C]:** Egyptian writing often uses ى for final ي throughout (فى، الذى). Treat as a systematic habit (SKILL.md §3).

### 1.6 Madda (آ) [E/A]

Written آ where hamza + long alif meet: آدم، آخر، الآن، القرآن، آلاف، آثار، مآل، الآخرة.

Common errors: أدم / ادم → آدم · اخر / أخر (= other/last) → آخر · الان → الآن · القران → القرآن · الاف → آلاف

**Traps [A]:** أخّر / أُخَر (delayed; other, plural) are valid without madda; flag آخر/أخر when the sense is unclear.

## P2 — Medium frequency

### 2.1 Medial hamza [E/C]

Seat follows the strongest of the hamza's vowel and the preceding letter's vowel: kasra (ئ) > damma (ؤ) > fatha (أ) > sukun (ء on the line).

| Examples | |
|---|---|
| ئ | سُئِل، بِئر، رئيس، مسائل، فئة |
| ؤ | سُؤال، مُؤتمر، تفاؤل، يُؤكِّد |
| أ | سأل، مسألة، رأس، يأخذ |
| ء | تساءل، قراءة، مروءة، عباءة |

Common errors: سؤل (verb) → سُئل · مسئلة → مسألة · قرائة → قراءة · تسائل → تساءل · مأمن ✓ · رأيس → رئيس

**Convention [C] (unify to house style, never mark as error):**
مسؤول/مسئول · شؤون/شئون · رؤوس/رءوس · يقرؤون/يقرأون · مئة/مائة

Not a convention: تفاؤل (noun) vs تفاءل (verb) are different words. Writing the noun as تفاءل is **[E]**.

### 2.2 Final hamza [E]

- After a voweled letter: on the seat of that vowel → قرأ، يقرأ، تكافؤ، تباطؤ، شاطئ، قارئ.
- After sukun or a long vowel: on the line → شيء، جزء، سماء، ضوء، بطء، مجيء.

Common errors: شيئ → شيء · مجيئ → مجيء · قارء → قارئ · تكافئ (noun) → تكافؤ · ضوئ → ضوء

**Convention [C]:** مبادئ vs older typographic مبادىء → modern default مبادئ.

With tanween al-fath: شيئًا، جزءًا (ء after a connecting letter takes a seat-less form + alif per standard: شيئًا، عبئًا); after alif no extra alif: سماءً، بناءً، ابتداءً.
Common errors: سماءاً → سماءً · جزئاً → جزءًا

### 2.3 Alif fariqa (ا after و) [E]

- Added after واو الجماعة in verbs: كتبوا، لم يكتبوا، لن يذهبوا، اكتبوا.
- **Not** added after the و of a sound masculine plural noun in construct: مهندسو الشركة، موظفو البنك.
- **Not** added after a root و in a verb: يدعو، نرجو، يسمو، يرجو.

Common errors: يرجوا → يرجو · ندعوا (we call) → ندعو · موظفوا → موظفو · كتبو → كتبوا · لم يحضرو → لم يحضروا

**Trap [A]:** ندعوا is correct if it means "they [plural] call" in subjunctive/jussive (لن يدعوا). Flag when the subject is unclear.

### 2.4 Tanween al-fath placement [C/E]

- **[C]** Position: on the letter before the alif (كتابًا، أيضًا) or on the alif (كتاباً، أيضاً). Unify to house style.
- **[E]** No extra alif after ة, after ء preceded by alif, or after ى: مدرسةً، سماءً، هدًى، مستشفًى.
  Errors: مدرسةاً → مدرسةً · سماءاً → سماءً · هدىً ✓ / هدًى ✓ (convention).
- **[E]** No tanween alif missing on nouns that need it in formal text: شكرا → شكرًا is **[C]** in casual registers (leave in chat/social).

### 2.5 لـ + الـ and لـ + ل [E]

- لـ + الـ → للـ: للطالب، للحساب (not لالطالب).
- لـ + الـ + word starting with ل → three lams collapse to two: للغة، لليوم، لللغة → للغة.

### 2.6 Weak-letter deletion in jussive and imperative [E/A]

The written form changes, so this is treated as spelling even though it is morphology.

| Verb type | Rule | Common errors → correct |
|---|---|---|
| Hollow (أجوف): قال، كان، باع | Middle long vowel drops after لم / لا الناهية / imperative | لم يقول → لم يقل · لم يكون → لم يكن · إن لم تقول → إن لم تقل · لا تخاف → لا تخف |
| Defective (ناقص): بنى، نسي، دعا، مشى | Final weak letter drops; short vowel stays | ابني (imperative) → ابنِ · لا تنسى → لا تنسَ · لم يمشي → لم يمشِ · ادعو → ادعُ · لم يدعو → لم يدعُ |

**Traps [A]:** ابني = "my son"; لا تنسى is correct when لا is نافية (indicative), not ناهية. Classify as Error only when the imperative/prohibitive reading is unmistakable from context.

## P3 — Lower frequency or higher ambiguity

### 3.1 ض / ظ [E]

Common confusion pairs and errors:

| Wrong | Correct | Meaning |
|---|---|---|
| ضهر | ظهر | appeared / back |
| ضلم | ظلم | injustice |
| عضيم | عظيم | great |
| ضروف | ظروف | circumstances |
| نضام | نظام | system |
| ظابط | ضابط | officer |
| ظمان | ضمان | guarantee |
| حظور | حضور | attendance |
| إظافة | إضافة | addition |
| ظرورة | ضرورة | necessity |

**Valid minimal pairs [A]:** ضل/ظل · ضن/ظن · حض/حظ · نضر/نظر (نضرة = freshness). Flag, do not auto-fix.

### 3.2 Other dialect-driven substitutions [E in MSA only]

Levantine and Egyptian speech merges ث→ت/س, ذ→ز/د, ظ→ض/ز, ق→ء. In MSA text these produce spelling errors:
مزكور → مذكور · تلاتة → ثلاثة · أزكى (smarter) ✓ vs أذكى ✓ — **[A]**, check meaning.
In dialect registers these spellings are intentional: leave them.

### 3.3 Spacing and attached particles [E]

- One-letter particles attach: و، ف، ب، ك، ل → والطلاب، فقط، بالحساب. Error: و الطلاب → والطلاب.
- No space before ، ؛ ؟ ! . : one space after.
- No space inside brackets, «», or "": «النص» not « النص »; "هل" not " هل".
- Collapse double spaces to one.
- يا is a separate word: ياطفل → يا طفل · يامن → يا من. (Quranic rasm such as يٰأيها is locked.)
- Quranic brackets ﴿ ﴾ are exempt from the inside-space rule; spacing there varies by edition and the content is locked.

### 3.6 Non-word typos [A]

A dropped, doubled, or swapped letter that produces a non-word (ريد for يريد، الحسباب for الحساب): flag with the most likely intended word. Never auto-fix, even in `fix` mode, because the intended word is a guess.
- ما + compound forms: ممّا، عمّا، فيما، كلّما (attached) · كلّ ما (separate when ما is a noun meaning "everything that"): **[A]**.

### 3.4 ابن / بن [C/A]

Classical rule drops the alif of ابن between two names in a lineage on the same line (محمد بن عبد الله). Modern practice varies. Treat as **[C]**; flag only if the document mixes forms. Never touch names written by their owner.

### 3.5 عبد + name [C]

عبد الله / عبدالله: both in use. Unify for generic text per house style; **lock** for real people's names.
